Intel or AMD: add this to the FastChannels service in your compose file, then recreate the container: 
devices:
  - /dev/dri:/dev/dri
Only if your server has /dev/dri; otherwise Docker won't start the container.
Docker Desktop on Windows (experimental): add this instead: 
devices:
  - /dev/dxg:/dev/dxg
  - /dev/dri:/dev/dri
volumes:
  - /usr/lib/wsl:/usr/lib/wsl:ro
If Docker says /dev/dri doesn't exist, your Docker VM has no render node: drop that line and capture will use the CPU.
NVIDIA (experimental): install the NVIDIA Container Toolkit on the server, then add: 
runtime: nvidia
environment:
  - NVIDIA_VISIBLE_DEVICES=all
  - NVIDIA_DRIVER_CAPABILITIES=compute,video,utility
