Getting started
  1. Set up a method. Pick one under Methods and fill in its settings.
  2. Turn on Bridge mode with the switch above.
  3. Enable a DRM-capable source. See Coverage for the ones each method supports, then add it on Sources.
  4. Run a Stream Audit on each source you want bridged. The audit detects DRM and marks eligible channels for bridge output; without it, existing channels still look like ordinary or disabled streams.
  5. Add the bridge M3U to your DVR from Feeds, alongside your regular feed.
