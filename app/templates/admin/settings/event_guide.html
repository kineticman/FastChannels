Event Channels
Guide data around one-off event channels such as ESPN+ games
Fill the guide before and after events
When enabled (default), an event channel's guide shows hourly Event Not Started blocks with its start time until the event begins, and Event Ended blocks for 24 hours after it. Without them, Channels DVR and other clients show an empty row, or fill it with placeholders named after the channel, which can look like the game is already on. The filler blocks have no categories, so they stay out of Sports and other genre filters.
