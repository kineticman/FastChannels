Optional scraped-only M3U playlists and XML guides for every feed
Enable native feeds
This switch applies to every feed. When off, FastChannels stops generating native M3U and XML files, hides their links on Feeds, and returns 404 from native URLs. Existing DVR sources using those URLs will stop working until you turn it back on. Standard, mixed, Gracenote and bridge outputs keep working.
Last native URL request (M3U or EPG):
While this switch is on, each native file is refreshed routinely for seven days after its first build or last request. After that, the switch stays on and the URL remains available; routine refreshes pause for that file. Its next request may wait for a rebuild and starts a new seven-day window.
