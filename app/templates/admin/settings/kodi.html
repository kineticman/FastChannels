Kodi HDMI Bridge Experimental Beta
Remote-trigger a Kodi/Fire TV device to play DRM channels, captured back in by an HDMI encoder
This feature is early and hands-on: it expects a Kodi install already sideloaded on the device with JSON-RPC and the FastChannels resolver addon set up. Nothing here does that setup for you yet — see docs/kodi-bridge-setup.md for the full walkthrough. Grab the resolver addon itself at {{ request_base_url }}/kodi/fc_bridge.zip — download it, then install it on the device via Kodi's Add-ons > Install from zip file.
Enable Kodi bridge
Turns the feature on. Needed before the device IP below does anything.
Keep alive
A background check pings the device every 45s and relaunches Kodi automatically if it's unresponsive (crashed, backgrounded, or just rebooted). Turn off to stop that polling, e.g. while testing manually.
Just the IP — JSON-RPC (:8080) and adb (:5555) addresses are derived from it automatically.
Where a bridged channel actually plays from once Kodi's been triggered. If you're capturing the Firestick's HDMI output with a USB capture card through Channels DVR's own native capture:// support, this is that capture channel's own stream URL — Channels DVR re-serves any of its channels at http://<host>:8089/devices/ANY/channels/<guide number>/stream.mpg. No standalone hardware encoder needed for that path.
