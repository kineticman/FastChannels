FastChannels Player Experimental Beta
Remote-trigger a Fire TV / Android TV device to play DRM channels, captured back in by an HDMI encoder
Requires the FastChannels Player app installed on the device (ADB debugging must be turned on first). Its decoded output is captured back in by an HDMI encoder — either a single fixed one, or a broader set of hardware driven through ah4c — for re-ingestion elsewhere (e.g. Channels DVR).
Enable FastChannels Player
Required before either capture method below takes effect. Only applies to a trusted subset of DRM sources: Sling, NBCUniversal TVE, PBS, Amazon Prime (free), DirecTV Stream, Vidaa, Philo, Roku, and Fubo.
adb port (:5555) is derived automatically. Used to adb-trigger playback and to install the app — shared by both capture methods below.
"Install" pushes the app to the device over adb — no manual sideload, and no need to touch "Apps from Unknown Sources" on the device (that setting only gates the on-device tap-to-install flow, not adb). Requires the IP address above to be saved first, and ADB debugging already turned on on the device itself.
Stop playback when nobody's watching
Detects idle bridged channels two ways: Channels DVR's own activity status, and a heartbeat from FastChannels' own /watch page while it's open. After ~5 minutes with neither signal, the device is stopped. This can't see a third-party client (Plex/Threadfin, a bare VLC playlist, etc.) pointed directly at the M3U — only enable this if Channels DVR and/or the FastChannels web player are the only ways bridged channels get watched. {% if not channels_dvr_url %}Channels DVR URL isn't configured — the DVR-activity signal won't work until it is (the /watch heartbeat still will).{% endif %}
Show captions when available
Renders an English subtitle/CC track when the stream advertises one. Works on most sources. Applies the next time a channel is triggered, not to a stream already playing.

Single HDMI encoder
The original capture method: one fixed encoder stream URL, e.g. Channels DVR's own capture:// source. Simplest option if you're already set up with the specific encoder FastChannels documents.
Where a bridged channel plays from once the device is triggered. With Channels DVR's native capture:// source, this is that channel's own stream URL: http://<host>:8089/devices/ANY/channels/<guide number>/stream.mpg.
ah4c
Drives FastChannels Player through ah4c instead of a single fixed encoder URL — useful if your HDMI encoder isn't the one FastChannels documents directly (ah4c already supports Hauppauge, Magewell, DeckLink, and any network encoder). Adds a second, ah4c-routed M3U option next to the standard one on the Feeds page.
Enable ah4c support
Off by default — leaves the single-encoder output above untouched.
Where ah4c itself is reachable — its /play/tuner/<channel> is what the generated M3U points at.
The exported scripts tell ah4c how to adb-trigger FastChannels Player and confirm playback started — drop them into ah4c's own mounted scripts directory (see the download for exact instructions).
