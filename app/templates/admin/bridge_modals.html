Update ah4c scripts

These small scripts tell ah4c how to start FastChannels Player on each TV device. ah4c's maintainers publish them with ah4c.

Filled in for you. Change it only if ah4c runs on another network.

In ah4c's settings or compose file, set UPDATE_SCRIPTS=true and set FASTCHANNELS_URL to the address above. Then updating ah4c also installs the latest scripts. Edits you make to the scripts are replaced whenever ah4c starts.

No ah4c restart needed. Container not named ah4c? Change that word. Edits you made to the scripts are replaced.
Other ways to install
First-time setup: in ah4c's settings, set STREAMER_APP to scripts/firetv/fastchannels and FASTCHANNELS_URL to the address above.
By hand: download the scripts and extract them into ah4c's scripts/firetv/fastchannels folder.

Set up ah4c for FastChannels

FastChannels fills in ah4c’s settings for you: the FastChannels scripts, this server’s address and your tuners. You see every change before anything is saved.

Don’t have ah4c yet? Start it with this compose file
Using Project One-Click? Its ah4c-minimal action sets up the same thing, so skip this file. Otherwise run it with docker compose up -d on the computer with your capture hardware, then come back and click Check ah4c. Settings stay out of this file on purpose: anything set here is locked and can only be changed here. Capture cards (Hauppauge, Magewell, DeckLink) also need a devices: entry. Network encoders such as LinkPi don’t.
